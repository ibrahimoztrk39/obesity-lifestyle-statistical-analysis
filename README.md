# STAT250 – Lifestyle Habits and Obesity Analysis

## Overview
This repository contains the final project for the STAT 250 course at Middle East Technical University. The study explores the relationship between obesity levels and various lifestyle factors, including dietary habits, physical activity, alcohol consumption, calorie monitoring, smoking behavior, and family history of obesity.

The analysis is based on a real-world dataset obtained from the UCI Machine Learning Repository and focuses on statistical inference, interpretation, and visualization of results.

## Dataset
- **Source:** UCI Machine Learning Repository  
- **Dataset:** Estimation of Obesity Levels Based on Eating Habits and Physical Condition  
- **Sample Size:** 2,111 individuals  
- **Countries:** Mexico, Peru, Colombia  
- **Variables:** 17 demographic, lifestyle, and behavioral variables

## Research Questions
- Is alcohol consumption frequency associated with obesity levels?
- Do calorie monitoring habits differ across obesity categories?
- Does physical activity frequency vary among different obesity groups?
- Is smoking behavior statistically different between obese and non-obese individuals?

## Methodology
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Chi-square tests of independence
- One-way ANOVA with post-hoc analysis
- Kruskal–Wallis non-parametric testing
- Two-sample test for equality of proportions
- Assumption checking and interpretation

## Tools
- R
- Python
- Statistical visualization techniques
- Academic reporting

## Key Findings
- Alcohol consumption frequency showed a significant association with obesity levels.
- Individuals who monitored their calorie intake were more likely to fall into lower obesity categories.
- Physical activity frequency decreased as obesity level increased, supported by both ANOVA and non-parametric tests.
- No statistically significant difference was found in smoking rates between obese and non-obese groups.
